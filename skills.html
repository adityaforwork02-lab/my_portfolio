My Skills

These are the technologies and areas I'm currently practising. I'm continuously improving through exercises and hands-on projects.

HTML

HTML (HyperText Markup Language) provides the structure of a webpage. I use elements such as headings, paragraphs, links, images, lists and sections to organise website content in a meaningful way.

CSS

CSS (Cascading Style Sheets) controls the presentation of webpages. It helps me work with colours, fonts, spacing, layouts, borders and responsive designs to make websites clearer and more attractive.

C++

C++ is a general-purpose programming language that helps me understand core programming concepts. I'm practising variables, data types, conditions, loops, functions and problem-solving.

Basic Web Design

Basic web design is about arranging information so that a website is easy to understand and navigate. I'm learning to create consistent page layouts, readable text, useful navigation and simple user interactions.
